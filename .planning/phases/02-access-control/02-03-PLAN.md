In the POST handler block, at the START of both the `add` branch and the `edit` branch (before the `foreach ($fields as $f)` loop), add group ID extraction:


Then, after the `foreach ($fields as $f)` loop that builds `$rowData` (but inside the `if (!$hasError)` block and before the `dbInsert`/`dbUpdate` call), append the group fields to `$rowData`:

```php

$rowData['edit_groups']  = !empty($editGroupIds)  ? implode(',', $editGroupIds)  : null;
```

**Change 3 — POST handler: ACL check before edit save:**

In the `edit` branch of the POST handler, before the `if (!$hasError)` block, add a canEditRow() guard. Fetch the existing row first:

```php
// Row-level edit permission check
$existingForAcl = dbGetRow("SELECT * FROM `{$tableName}` WHERE id = ?", [$recordId]);
if (!$existingForAcl || !canEditRow($existingForAcl)) {
    http_response_code(403);
    $error = 'You do not have permission to edit this record.';
    $hasError = true;
}
```

Place this block at the very start of the `elseif ($postAction === 'edit' && $recordId)` branch, before the `$rowData = []; $hasError = false;` lines (so $hasError is set correctly and the rest of the branch skips the DB update).

**Change 4 — POST handler: add `status` field from POST if present:**

In both the add and edit branches, after the `foreach ($fields as $f)` loop, also capture the status field submitted by the form (it will exist after Plan 03 adds it to the form in Task 2):

