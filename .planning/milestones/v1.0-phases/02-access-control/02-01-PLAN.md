Create functions/acl.php as a pure PHP library file (no require_once calls needed — the framework bootstrap already loads auth.php and database.php before any custom_script runs).

Implement exactly these five functions in this order:

**1. getUserGroupIds(?int $userId = null): array**
- Uses a static $cache array keyed by user ID to avoid repeated DB queries per request
- If $userId is null, call getCurrentUserId(); if still null/falsy return []
- If cache miss: $groups = getUserGroups($userId); cache and return array_map('intval', array_column($groups, 'id'))
- If cache hit: return $cache[$userId]

**2. canViewRow(array $row, ?int $userId = null): bool**
- Admin bypass first: if hasPermission('admin_access', $userId) return true
- If empty($row['view_groups']) return true (NULL or '' means open to all)
- Parse: $allowed = array_filter(array_map('intval', explode(',', $row['view_groups'])))
- If $allowed is empty after parsing, return true
- Return !empty(array_intersect(getUserGroupIds($userId), $allowed))

**3. canEditRow(array $row, ?int $userId = null): bool**
- Admin bypass first: if hasPermission('admin_access', $userId) return true
- If empty($row['edit_groups']) return true
- Parse: $allowed = array_filter(array_map('intval', explode(',', $row['edit_groups'])))
- If $allowed is empty after parsing, return true
- Return !empty(array_intersect(getUserGroupIds($userId), $allowed))

**4. filterRowsByViewAccess(array $rows, ?int $userId = null): array**
- Return array_values(array_filter($rows, fn($row) => canViewRow($row, $userId)))
- The array_values() call resets numeric keys so the result is a sequential array

**5. formatGroupIds(?string $groupIds): string**
- If empty($groupIds) return '<span class="text-muted">All Users</span>'
- $ids = array_filter(array_map('intval', explode(',', $groupIds)))
- If empty($ids) return '<span class="text-muted">All Users</span>'
- Build $placeholders = implode(',', array_fill(0, count($ids), '?'))
- $rows = dbGetRows("SELECT name FROM user_groups_list WHERE id IN ($placeholders) ORDER BY name", $ids)
- $names = array_column($rows, 'name')
- Return htmlspecialchars(implode(', ', $names))
